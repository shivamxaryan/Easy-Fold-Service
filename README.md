# 🧼 Laundry Service Web Application

A web application for laundry services where **buyers** can schedule services like **Washing**, **Ironing**, and **Pickup/Drop**, and **sellers** can offer their laundry-related services.

---

## 🛠️ Tech Stack

- **Java 21**
- **Spring Boot 3.5.0**
- **Spring Data JPA**
- **PostgreSQL**
- **Lombok**
- **Gradle**

---

## 📦 Features

- User registration (Buyer & Seller roles)
- Phone & Address management
- Service catalog for sellers
- Order placement with pickup/drop options
- PostgreSQL integration

---

## 🚀 Getting Started

### Prerequisites

- Java 21
